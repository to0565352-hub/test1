# Bloom — Ko-fi 风格创作者平台 MVP

这是一个可以在 Windows 本地运行、可继续开发的全栈原型。使用 Node.js 内置模块，不需要先安装一堆 npm 依赖。

## 已实现
- 注册 / 登录（密码使用 scrypt 哈希存储）
- 创作者主页与资料编辑
- 发布作品、标签搜索
- 创建社区并关联标签
- 创作者列表、作品广场、社区列表
- 自定义金额、留言、打赏意向记录
- JSON 数据持久化，重启后内容仍然保留
- 响应式布局，手机和电脑浏览器均可使用

## 尚未实现（请务必注意）
- 没有接入真实支付宝 / 微信支付
- 打赏记录是“待付款意向”，不是到账记录
- 没有邮件验证、密码重置、管理后台、内容审核、限流、生产级会话存储等生产功能
- 会话暂存在内存中，服务重启后需要重新登录
- 当前版本是本地 MVP，不要直接公开部署承载真实用户或真实支付

## Windows 启动
1. 安装 Node.js 18 或更高版本（https://nodejs.org/）。
2. 解压项目。
3. 在项目目录地址栏输入 `cmd` 并回车，打开终端。
4. 执行：

   ```bash
   npm start
   ```

5. 浏览器打开 http://127.0.0.1:3000

没有 `npm install` 步骤，因为本项目只用 Node.js 内置模块。

## 数据在哪里
数据保存于 `data/db.json`。开发测试时可以备份或重置这个文件；删除文件内容会清空用户、作品、社区和打赏意向记录。

## 后续接入真实支付前
需要确认商户主体与支付产品资格，然后实现服务端创建订单、支付渠道签名校验、异步通知验签、订单幂等、退款处理、日志和风控。不要只根据浏览器跳转或用户点击按钮就把订单标记为已付款。

## 安全提示
此项目只适合本地测试和功能原型。正式上线前至少需要 HTTPS、持久化会话/数据库、CSRF 防护、速率限制、输入校验、备份、日志、内容审核和安全测试。
